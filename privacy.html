Privacy policy

n8n-automation · last updated 15 September 2026

This policy covers the personal automation project described on the homepage. The project is operated by a single individual for their own Google account. It has no other users and collects no data from anyone else.

What the software accesses

With the account owner's Google authorization, the software reads:

  • Gmail messages. Message identifiers, thread identifiers, timestamps, sender and recipient addresses, subject lines, and message bodies. These are used to recognize which messages relate to a job application and what stage that application has reached.
  • Google Sheets. Rows in two spreadsheets in the owner's own Drive, which hold the application records and a stored position marker recording how far through the mailbox the software has read.

What it writes

The software writes only to the owner's own spreadsheets: application rows, status events, and the position marker. It does not send, delete, modify, or reply to email. It does not create, delete, or share any other file.

Where the data goes

Nowhere it was not already. Message content is processed on the owner's own computer, by software running locally, and the results are written back into the owner's own Google account. There is no external server, no analytics, no third-party data processor, and no other person with access.

One exception worth stating plainly: short status notifications — for example, that an interview invitation arrived from a named company — are delivered to the owner through a private Telegram bot addressed to the owner's own chat. Telegram carries those messages. No full message content is sent this way.

Retention

Records stay in the owner's spreadsheets until the owner deletes them. Copies of message data held temporarily during processing are kept in the local n8n execution history and are removed when that history is pruned or the container's data volume is deleted.

Sharing and sale

Data is never sold, rented, shared, transferred, or used for advertising, profiling, or training machine-learning models. Google user data obtained through these scopes is used solely to provide the tracking function described above.

Withdrawing access

The account owner can revoke this software's access at any time at myaccount.google.com/permissions. Revocation stops all further access immediately. Records already written to the owner's spreadsheets remain there and can be deleted directly.

Changes

If what the software accesses changes, this page is updated and the date at the top changes with it.
