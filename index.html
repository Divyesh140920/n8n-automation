n8n-automation

A personal automation project. Not a public service.

This is a self-hosted n8n instance run by one person, on one laptop, for one Google account. It reads job-application email and keeps a private spreadsheet up to date so the status of each application does not have to be tracked by hand.

What it does

  • Reads incoming mail to recognize application confirmations, interview invitations, assessments, offers, and rejections.
  • Records each of those as a row or event in a Google Sheet owned by the same account.
  • Sends the account owner a Telegram message when something needs attention.

Who can use it

Nobody else. There is no sign-up, no hosted version, and no other user. The Google authorization exists so the software can reach the owner's own mailbox and the owner's own spreadsheet. If you have arrived here from a consent screen and you are not the owner of this project, you should not grant access.

Data

Everything stays inside the owner's Google account and the machine the software runs on. Nothing is sold, shared, or sent to a third party. The privacy policy sets this out in full.
